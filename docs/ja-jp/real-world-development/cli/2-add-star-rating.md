Copilot CLI をインストールし、会話を試したので、次はプロジェクトに最初の変更を加えましょう。変更は小さなものです。ゲームのデータにはすでに星評価がありますが、ホーム ページのゲーム カードにはまだ表示されていません。エージェントに表示を依頼し、変更をレビューして、最初の pull request としてマージします。

このレッスンでは、次の操作を行います。

- 機能ブランチで、目的を絞った Copilot の会話を開始します。
- エージェントにプロジェクトの小さな変更を依頼します。
- `/diff` で変更をレビューします。
- アプリを実行し、転送されたブラウザーで変更を確認します。
- 最初の pull request を開いてマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価を設定でき、ゲームの詳細ページにはすでに表示されています。しかし、ホーム ページのゲーム カードに表示されるのはタイトル、カテゴリ、パブリッシャー、説明だけです。最初の練習として、各カードに既存の評価を表示するようエージェントに依頼します。小規模で独立した変更なので、最初のセッションにぴったりです。

## 会話の構成

**会話**は、Copilot CLI でタスクに取り組む場所です。Copilot アプリとは異なり、通常の CLI の会話では、専用の worktree を作成せず、ターミナルで現在チェックアウトされているリポジトリと Git ブランチを使用します。保存した会話に後から戻ることができますが、ファイルとブランチは通常の Git の状態としてディスク上に残ります。

会話では、3 つの内容を確認できます。自分のプロンプトとエージェントの応答、エージェントがファイルを調査および編集する際のツール操作、そして `/diff` で確認できる変更です。

## 会話を開始して変更を依頼する

新しい会話を始めて、機能の実装に取りかかりましょう。

1. Codespace に戻ります。
2. ターミナルが開いていない場合は、<kbd>Control</kbd>+<kbd>\`</kbd> (Mac) または <kbd>Ctrl</kbd>+<kbd>\`</kbd> (Windows/Linux) を押します。
3. まだ Copilot を起動していない場合は、次のコマンドを実行します。

   ```bash
   copilot --yolo
   ```

4. スラッシュ コマンド `/new` を実行して <kbd>Enter</kbd> を押し、新しいセッションを開始します。
5. 次のプロンプトで変更を依頼します。

   ```plaintext
   一覧ページのゲーム カードに、各ゲームの starRating を 5 段階で表示してください。評価が null の場合は "評価なし" と表示してください。カードのレイアウトはそのままにして、テストを追加し、関連するチェックを実行してください。
   ```

Copilot がプロジェクトを調査し、ゲームの詳細を表示するファイルを見つけて、必要なコードを作成します。Copilot CLI を使って新しい機能を追加できました。

## 差分をレビューする

小さな変更でも、AI が生成した変更はすべてマージ前にレビューします。Copilot CLI で変更を確認しましょう。

1. `/diff` を入力して、変更されたすべてのファイルを確認します。
2. ゲーム カードに数値評価がある場合はその値が、`starRating` が `null` の場合は `評価なし` が表示されることを確認します。
3. テストで両方の状態がカバーされていることを確認します。
4. Copilot が実行したチェックの結果を確認し、失敗があれば修正を依頼します。
5. レビューが終わったら、<kbd>Esc</kbd> を押して差分画面を閉じます。

> [!NOTE]
> すべての生成 AI ツールと同様に、Copilot は確率的に動作するため、生成されるコードは異なる場合があります。特定の実装を期待するのではなく、動作を確認してください。

## 変更を確認する

コードを読んだだけで動作すると判断するのではなく、Copilot に Web サイトを起動してもらい、Codespaces から転送されたブラウザーで更新後の UI を確認しましょう。

1. Copilot にアプリの起動を依頼します。

   ```plaintext
   ブラウザーで星評価の変更を確認できるように、アプリを起動してください。URL を教えて、サーバーは実行したままにしてください。
   ```

2. Codespaces でポート `4321` が使用可能と表示されたら、**Open in Browser** を選択します。
3. ゲーム カードに 5 段階の評価が表示されることを確認します。
4. Copilot に戻り、起動したサーバーの停止を依頼します。

   ```plaintext
   起動した開発サーバーを停止してください。
   ```

## 最初の pull request を開いてマージする

これで機能を作成できました。次は pull request (PR) を作成して、新しいコードをプロジェクトにマージします。

1. 既定のエージェントに変更のコミットを依頼します。

   ```plaintext
   レビュー済みの星評価の変更を、適切なコミット メッセージでコミットしてください。
   ```

2. `/pr create` を入力します。Copilot CLI は PR の作成時に既存のコミットを push し、PR の URL を表示します。
3. <kbd>Command</kbd> (Mac) または <kbd>Ctrl</kbd> (Windows/Linux) を押しながら、Copilot CLI に表示された URL を選択して PR を開きます。
4. 変更されたファイルとチェックをレビューします。
5. 準備ができたら **Merge pull request** を選択し、マージを確定します。
6. Codespace に戻り、`/exit` で Copilot CLI を終了します。
7. ローカルの `main` を更新します。

   ```bash
   git checkout main
   git pull
   ```

- 機能ブランチで、目的を絞った Copilot の会話を開始しました。
- エージェントにゲーム カードの小さな変更を依頼しました。
- `/diff` で変更をレビューしました。
- アプリを実行し、転送されたブラウザーで星評価を確認しました。
