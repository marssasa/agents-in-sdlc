Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante escenarios realistas, una aplicación completa y un trabajo pendiente compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia de financiación colectiva de juegos de mesa con temática de desarrollo. El trabajo pendiente de tu equipo ya está registrado como incidencias de GitHub y puedes empezar por cualquiera de ellas. Incluye tareas funcionales, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a la forma en que quieres desarrollar. Cada taller empieza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia los modos de sesión, colabora en canvas y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
