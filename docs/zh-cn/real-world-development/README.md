通过真实场景、完整应用和共享积压工作，探索 GitHub Copilot 在整个软件开发生命周期中的应用。你将通过迭代来规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发者。这是一家虚构公司，为以开发者为主题的棋盘游戏提供众筹服务。团队积压工作已记录为 GitHub issue，你可以直接开始处理。其中既有筛选和分页等功能任务，也有无障碍和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。选择最符合你开发方式的环境。每个工作坊都有独立的设置流程，并使用共享的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。通过 Plan 和 Autopilot 模式、说明、skills、自定义智能体、Playwright MCP、Agent Merge 和实用斜杠命令完成工作。

### [GitHub Copilot 应用][app]

并行运行智能体会话、切换会话模式、在 Canvas 中协作，并通过桌面应用管理 GitHub issue 和拉取请求。

### [Copilot 云端智能体][cloud]

将 GitHub issue 分配给异步智能体、指导其工作、监控进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
